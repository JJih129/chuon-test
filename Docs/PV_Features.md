# 추온(CHUON) — 구현 기능 정리 (PV v1 동봉, 2026-11-10)

PlayX4 2026 전시 데모 기준. 근거: `Docs/Roadmap_Loop.md` 반복 기록, 커밋 로그, 각 설계 문서. 수치는 개발 빌드 QA 봇 측정값(목표 사양이 아닌 개발 노트북, RTX 2050)이다.

## 1. 데모 흐름 (약 10분)
| 순서 | 장면 | 내용 |
|---|---|---|
| 1 | 팀 로고 → 타이틀 → 부팅 | 패드/키보드 메뉴, 옵션 |
| 2 | **침투 튜토리얼 (VR 리허설)** `Tutorial` | 해 질 녘 도시 블록, 본사 타워(TSUKASA 엠블럼)가 위니. 골목 → 스캐너 커튼 → 검문소 → 하역장 → 측면 출입구 → 로비 유리문. 17단계 가르치기 → 시험 → 비틀기, 사망 대신 "재동기화" |
| 3 | **오프닝 시네마틱** | 은신처 회상(정보 유출) → 추온 각성 → 새벽 본사 올려다보기 (30 s) |
| 4 | **본사 로비** `Level_Facility` 상층 | 경보 + 드론 출격 리빌, 스카이덱 내려다보기, 잡몹 조우(안드로이드 → 드론 → 안드로이드+집행관+터렛), 전용 엘리베이터 |
| 5 | **엘리베이터 하강** | 층 표시·조명 끊김·EGO/추온 대화 (13 s) |
| 6 | **Type-D 보스전** (격납고) | 리빌 → 3페이즈, 과열 연출, 브레이크·처형, 궁극기 |
| 7 | **엔딩** | Type-D 쓰러짐 → 화면 베기 전환 → 츠카사 홀로그램 "결국 일어나 버렸나.. 하지만 넌 아직 내가 설계한 궤도 위를 걷고 있을 뿐이다." → 크레딧 |

## 2. 전투 시스템
- 약공/강공 콤보, 가드, **패링**(연타 큐, 3타째 금색 큐 패링 → 긴 경직), 회피·**퍼펙트 회피**(슬로·잔상·측면 이동), 회복 앰플(35%, 취소 가능), 균형(Balance) 게이지, 히트스톱.
- **정직한 텔레그래프**: 공지 시간 = 실제 남은 시간(오차 ≤ 0.005 s 측정). 색 언어 — 금(패링 가능) / 빨강(회피 전용) / 호박(강공·가드 브레이크) / 자홍(가드 불가), 색각 보정 팔레트. 바이저·무기 전조 + 바닥 데칼(판정 범위와 일치) + 타입별 큐 효과음.
- **흑백 흡수**(URP 피처): 패링·처형·궁극기·페이즈 2 순간 화면이 흑백, 추온/대상만 색 유지.
- **브레이크 → 처형**(5 s 창), **궁극기 '위상단절검'**: 코어 플레어 → 흡수 → 연속 베기 → 시간 정지 → **화면 직선 베기**(원신·스타레일풍 화면 분할) → 색 복귀. 전투당 1회, 건너뛰기 가능.
- 보스 Type-D: 장갑 22파츠(Blender, 21.8k tris), 에너지 코어, 페이즈별 균열·과열(증기·불티·열광), 검기·충격파·그림자 도약 패턴, 난이도 프로필(쉬움/보통/어려움).
- 카메라: 소울라이크 리그(자유/락온, 충돌, 화면 밖 위협 화살표, 옵션).

## 3. 잡몹 (츠카사 보안 병력)
| 적 | 역할 | 특징 |
|---|---|---|
| 경비 안드로이드 | 패링 교보재 | 3타째 금색 큐 → 패링 시 2.2 s 경직, 빨강 찌르기(회피 전용) |
| 방패 집행관 | 탱커 | 정면 약공 막힘 → 강공/측면/밀치기 패링으로 가드 붕괴 |
| 센트리 터렛(벽/바닥) | 공간 제어 | 스캔 → 레이저 추적 → 빨강 고정 → 5연발(옆으로 한 걸음) |
| 순찰 드론 | 원거리 견제 | 0.65 s 이상 정직한 빨강 경고 |
- 공통 AI: 시야·청각·동료 경보, **공격 토큰**(근접 2 / 원거리 1 동시), 원 돌기, 무한 경직 방지.

## 4. 시네마틱 (Timeline + Cinemachine, 9개 장면)
오프닝 · 튜토리얼 VR 부팅/종료 · 로비 경보·드론 리빌 · 스카이덱 · 엘리베이터 하강 · Type-D 리빌 v2 · 페이즈 과열(비점유) · 처형/궁극기 · 엔딩(츠카사 홀로그램). 전부 건너뛰기(길게 누르기 0.7 s), 재도전 시 생략, 레터박스·자막 옵션 준수, 게임플레이 복귀 0.35 s 블렌드. 1회 시청 약 87–96 s.

## 5. 옵션·접근성·입력
- 오디오: 마스터/음악/효과음/음성 볼륨(ChuonMixer, 리미터·더킹), 생성 BGM(MusicDirector 상태 전환).
- 그래픽: 해상도(W×H@Hz 저장)·전체화면·VSync·목표 FPS·품질·밝기·모션 블러.
- 접근성: **번쩍임 강도**(0이면 섬광·반전·글로 제거), **흑백 흡수 끄기**, 카메라 흔들림, 자막 크기·배경, 색각 보정 큐 색, 레터박스, 본 연출 다시 보지 않기.
- 입력: **게임패드 전체 지원**(Input System, 메뉴 내비게이션, 장치별 글리프 자동 전환), **키 리바인딩**(충돌 교체, 초기화).
  - 기본 조작(키보드·마우스 / 패드): 이동 WASD / 좌스틱, 약공 좌클릭 / RB, 강공 우클릭 / RT, 가드·패링 E / LB, 회피 Shift / B, 락온 Tab·휠 클릭 / R3, 회복 Q / X, 궁극기 R / LT, 상호작용 F / A, 일시정지 Esc / Start, 콤보 표 C / Y.

## 6. 품질·성능 (개발 빌드 QA)
- 전체 흐름 스모크(TeamLogo → Credits, 연출 포함): 에러 0 / 예외 0 (반복 14C).
- 보스 봇 승률: 숙련 0.9 → 9/10, 0.6 → 2/3, 0.4 → 1/3 (반복 14A).
- 튜토리얼 봇 17/17 단계, 강제 완료 0.
- FPS: 보스전 평균 120 / 1% 저점 104 (반복 14S), 튜토리얼 113 / 85, 시네마틱 1% 저점 79–118. 궁극기 시작 최악 프레임 34 ms.

## 7. 실행 방법
- 개발 빌드: `Builds/QA_Iter14C/ChuOn.exe` (또는 최신 `Builds/QA_Iter*`). 처음 실행 시 Windows 방화벽 창이 뜨면 취소해도 된다(네트워크 미사용).
- 에디터: Unity **2022.3.62f3**(업그레이드 금지), `Assets/Scenes/TeamLogoScene.unity` 부터 Play. 바로 테스트하려면 `Tutorial` 또는 `Level_Facility` 를 열고 Play.
- 개발 전용 키: F10 테스트 모드(피해 10% / 무적, 화면 상단 표시), F12 전투 디버그 HUD. 릴리스 빌드에는 포함되지 않는다.
- QA 명령줄(개발 빌드): `-qaFlowSmoke`, `-qaScene Level_Facility -qaFullRun -qaBot 0.9`, `-qaScene Tutorial -qaTutorialRun -qaBot 0.9`, `-qaSkipCinematics`.

## 8. PV v2 (2026-11-10)
- 파일: `Builds/PV/Chuon_PV_v2_master.mp4`(1080p60 H.264 CRF 16, AAC 320k, 92.3 s, 108 MB) / `Builds/PV/Chuon_PV_v2_web.mp4`(CRF 20, 64 MB). 라우드니스 -13.9 LUFS.
- 구성(132 BPM, 마디 단위 컷): 콜드 오픈(오프닝 시네마틱) → 츠카사 로고 → 침투 튜토리얼(패링·퍼펙트 회피·가드 브레이크가 다운비트) → 타이틀 CHUON/추온 → 본사 로비(경보·드론·스카이덱·잡몹) → 엘리베이터·Type-D 보스전 → 궁극기 '위상단절검'(화면 직선 베기: 선 → 홀드 → 분할 → 복귀, 0.3배 슬로) → 엔딩(츠카사 홀로그램) → 엔드 카드(PLAYX4 2026 DEMO).
- 촬영: 에디터 Play 모드 실시간 캡처(QA 봇 0.95, 퀘스트 패널 숨김, 게임 BGM 끔 → 효과음만), 음악은 `Tools/PV/pv_music.py` 생성곡(라이선스 문제 없음). 편집 정의: `Tools/PV/edl_pv_v2.json`, `Tools/PV/score_pv_v2.json`.
- 재생성: `python -X utf8 Tools/PV/pv_music.py Tools/PV/score_pv_v2.json Temp/pv/PV_Score_v2_GEN.wav` → `python -X utf8 Tools/PV/make_pv.py Tools/PV/edl_pv_v2.json --sheet Temp/pv/Chuon_PV_v2_sheet.png` (원본 테이크 `Recordings/PV/*_av.mov` 필요, git 제외).

## 9. PV 제작 도구 (이번 작업)
- `Assets/Scripts/Debug/PV/PvFrameCapture.cs` (개발 전용): Play 모드 실시간 캡처 — 게임은 실시간으로 돌고 화면을 AsyncGPUReadback → ffmpeg(Intel QSV H.264)로 1080p60 CFR 기록, 활성 AudioListener 믹스를 WAV 로 동시 기록. (Unity Recorder 고정 프레임 모드는 에디터가 60 fps 미만이면 비스케일 시계를 쓰는 연출·히트스톱이 영상에서 빨라져 실시간 캡처로 대체.)
- `PvRunDirector.cs` / `PvTakeMarkers.cs` (개발 전용): QA 봇으로 튜토리얼 → 엔딩까지 진행(옵션: 오른쪽 위 퀘스트 패널 숨김, 게임 BGM 끄고 효과음만 녹음), 패링·퍼펙트 회피·궁극기·브레이크·연출 시각을 마커 파일로 기록(컷 지점 찾기).
- `Assets/Editor/PV/PvRecorder.cs`: 메뉴 `Tools/Chuon/PV/*` (Recorder 방식 / 실시간 방식 시작·정지).
- `Tools/PV/make_pv.py`: EDL(JSON) → 비트 단위 컷(BPM), 화이트 플래시·xfade 전환, 슬로모(모션 보간), 타이틀/로고/엔드 카드, 하단 자막, 음악 큐·효과음·게임 사운드 믹스 + 2패스 라우드니스(-14 LUFS), 마스터(CRF 16)·웹(CRF 20), 콘택트 시트.
- `Tools/PV/pv_music.py`: PV 전용 생성 음악(라이선스 문제 없음).

## 10. 알려진 이슈 (반복 15 후속 포함)
- 시네마틱 첫 프레임 히치(경보 78 ms, 엘리베이터 59 ms) — 스테이지 예열 예정.
- 튜토리얼 VR 부팅 컷 일부가 오버레이에 가려짐.
- Type-D 인트로 길이 미결정(7 s vs 17.6 s), 궁극기 시간정지 카메라 구도(어둡고 먼 후방), 도시 블록 아트 패스, 츠카사 홀로그램 디테일, 크레딧 포커스 복귀.
- 퀘스트 패널의 긴 목표 문구가 칸 밖으로 잘림(예: "복도를 따라 본사 로비로 …").
- (PV 촬영 중 발견) 페이즈 3 과열 연출의 증기 파티클이 흰 네모 블록으로 보임(텍스처/재질 문제 추정).
- (PV 촬영 중 발견) 한 테이크에서 페이즈 3 이후 Type-D 가 단색 자홍(에러 셰이더처럼)으로 렌더링되어 엔딩까지 유지됨 — 다른 테이크에서는 정상(붉은 장갑). 재현 조사 필요.
- (PV 촬영 중 발견) 로비 경보 연출: S2(추온 얼굴 클로즈) 카메라가 바닥을 비춤, S4(등 뒤 OTS)가 하층 격납고를 비춤. 플레이어가 바로 전투에 들어가면(IsCombatActive) 경보 연출이 생략되고 기존 점멸로 대체됨.
- (PV 촬영 중 발견) 궁극기 시작 컷이 웅크린 추온을 엉덩이 높이 뒤에서 잡음(로우 프레이밍), 오프닝 각성 컷(부감·일어서기)도 하체 위주 — 구도 조정 권장.
- BGM은 절차 생성 임시 음원(정식 음원은 라이선스 확인 후 교체). 실제 패드 UI 검증·타임라인 볼륨 Play 검증 남음.
- 출시 게이트 미충족 항목: 릴리스 빌드 전체 흐름, 30분 연속 플레이, 플레이스홀더 아트 0, 키오스크 모드(전시용).
