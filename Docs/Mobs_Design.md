## 1. 텔레그래프 색 언어 (보스와 동일)

| 큐 | 색 (일반 / 색각 보정) | 플레이어 대응 | 페이로드 |
|---|---|---|---|
| 없음(일반) | — | 가드 · 패링 · 회피 모두 가능 | canParry/canGuard |
| **패링 가능** | 금/주황 / 노랑 | 패링 → 긴 경직(리포스트) | canParry, canGuard |
| **회피 전용** | 빨강 / 버밀리언 | 가드·패링 불가, 옆으로 피하기 / 퍼펙트 회피 | unblockable, canPerfectDodge |
| **강공** | 호박 / 파랑 | 막으면 가드 브레이크, 패링 가능 | causesGuardBreak, canParry |
| 가드 불가 | 자홍 / 적자색 | (잡몹 미사용, 예약) | unblockable |

큐 = 헬멧(바이저)/센서 앞 HDR 섬광 (`BossPatternHandTelegraph`, 보스와 같은 머티리얼) + 바닥 데칼 (`BossGroundTelegraph`, 채움이 판정 순간 끝에 닿음) + 타입별 효과음 (`Resources/Audio/TelegraphCue_*`).
**정직한 큐**: `EnemyBrain` 이 공격 시작 시 판정 시각 `hitAt` 을 정하고 큐를 `hitAt − lead` 에 같은 시계(Time.time)로 발행한다. 공지 시간 = 실제 남은 시간(프레임 지연 시 남은 시간 그대로 공지) → 오차 ≤ 1프레임. QA: `EnemyBrain.LastCueHonestyError`.
바닥 데칼은 큐 순간 위치에 고정되고 모양 = 실제 판정 사각형(전방 [0, 돌진+사거리] × 폭) — 데칼 밖이면 맞지 않는다.

인지(공통 `EnemyPerception`): 시야 원뿔(안드로이드 16m/120°, 집행관 14m/110°, 터렛 18m/70° 센서, 드론 14m/140°) + 가림 레이 + 2.2m 근접 감지 + 청각(플레이어 공격 시작 이벤트, 9–12m) + 피격 즉시 경계 + 동료 경보(반경 9m, 종류 무관, `EnemyAlertNetwork`). 대상을 6s 이상 놓치고 28m 밖이면 경계 해제.
상태 기계(`EnemyBrain`): Idle / Patrol → Alert(발견 비프 + 칼 뽑기 0.65s) → Approach → Strafe ↔ Attack → Recover → (Stagger) → Dead(힘 빠짐 애니 → 2.4s 후 1.1s 동안 바닥으로 가라앉고 비활성; 드롭 없음).
경직: 포이즈 0 → Stagger 1.6s(리포스트 창). 슈퍼아머가 아닌 공격/이동 중 피격 = 0.32s 움찔(연격 중단). 1.6s 안에 3번 움찔하면 1.8s 면역(안드로이드는 백스텝) — 무한 경직 방지. 포이즈는 2.5s 후 16/s 회복.

## 3. 공격 토큰 규칙 (군중 예절)

`EnemyAttackTokenDirector` (정적, 대상별):
- **근접 토큰 최대 2**, **원거리 토큰 최대 1** (드론 + 터렛 공유 → 탄막이 겹치지 않는다).
- 토큰은 접근 시작 ~ 연격 종료까지 보유, 반납 후 슬롯 쿨다운 근접 0.35s / 원거리 0.7s, 보유 시간 만료 시 자동 반납(사망·비활성 누수 없음).
- 토큰이 없는 근접 적은 중거리 원(안드로이드 4.6m, 집행관 4.0m)에서 대상을 바라보며 옆걸음, 다른 교전 적과 50° 이상 벌린다. 0.3–0.55s 간격으로 토큰 재요청, 개인 공격 쿨다운 1.1–2.0s(집행관 1.6–2.6s).
- 토큰을 쥐고 3.5s 안에 못 닿으면 양보. 대상이 1.3m 안으로 파고들면 대기 중 안드로이드는 백스텝.
- 드론: `useAttackTokens`(Mob_PatrolDrone 켬, 기존 로비 드론 꺼짐=기존 동작) — 텔레그래프 순간 원거리 토큰이 없으면 사격을 0.3s+리드 만큼 미룬다.

## 4. 배치 가이드

공통: 전투 공간 중앙은 비우고(카메라·락온), 터렛은 벽/기둥 앞 0.4m 이상 떨어뜨리지 않는다. 한 교전에 근접 3 + 원거리 2 이하. 회복 구간(전투 없는 복도)을 교전 사이에 둔다. 스폰 시 적은 씬 루트(부모 없음)에 둔다 (패링 통지 라우팅, 아래 위험 참조).

### 외곽 침투 튜토리얼 (다음 반복) — 가르치기 → 시험 → 비틀기
1. **가르치기**: 하역장 — 등을 보인 안드로이드 1(Patrol, 순찰 지점 2). 은신 접근 후 선공 → 3타 금색 패링 반복(대사 없이 금색 섬광 + 바닥 금색 데칼). 실패해도 HP 90 이라 부담 없음.
2. **가르치기 2**: 좁은 통로 + 벽 터렛 1 — 빨강 직선 레이저를 보여 주고 옆 칸으로 피하게 한다 (통로 폭 ≥ 3m).
3. **시험**: 주차 램프 — 안드로이드 2 + 드론 1. 토큰 규칙상 동시에 2명만 베고 드론 사격은 한 번에 하나 — 공정한 압박.
4. **비틀기**: 게이트 앞 집행관 1 + 바닥 터렛 1 — 정면 약공격은 막힌다 → 측면 돌기/강공/밀치기 패링. 터렛 직선이 집행관 뒤로 지나가게 배치해 '집행관을 방패 삼아' 움직이는 해법도 허용 (터렛 탄은 적에게 맞지 않음).

## 5. 검증 / 미검증
- 컴파일 0 오류. 프리팹 빌더는 프리뷰 씬에서만 작업(열린 씬 미변경).
- 반복 12C Play 검증: 히트 양방향, 3타 패링 → 경직, 방패 정면 약공 막기/강공 붕괴, 터렛 레이저→고정→연사 회피, 락온 전환/사망 해제, HP 바(월드 캔버스 수정), 토큰 동시 근접 ≤2, 큐 오차 ≤ 반 프레임(판정 프레임 반올림). 집행관: 방패 자세에서 방패 전진 + 배턴 늘어뜨림(관통 수정), 밀치기 준비 코일(뒤로 젖힘 → 판정 직전 튕김).
- (이전 기록) Play 모드 미검증: 애니메이션 리타깃 모양, 장갑/무기/방패 부착 정렬, 판정·큐 체감, NavMesh 이동(Level_Facility 의 NavMesh-Facility 에서 Warp 시도, 없으면 직접 이동), 터렛 피벗 축. QA 체크: `EnemyBrain.LastCueHonestyError` |≤ 0.03s|, `EnemyAttackTokenDirector.ActiveCount(player, Melee) ≤ 2`.
