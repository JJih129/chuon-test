# 스토리 기준 (팀 기획 문서 요약)

출처: 팀 드라이브 `기획/📜세계관 및 스토리 기획` — 「세계관 및 스토리 기획 문서」, 「인물 프로필」, 「대사 스크립트 기획」.
게임 속 표기·대사·환경 연출은 이 문서를 기준으로 맞춘다. (아라사카/밀리테크는 **아트 스타일 참고**일 뿐, 게임 속 이름이 아니다.)

## 세계관
- 근미래, **극동풍 기술 국가**. 천재 과학자 **츠카사**가 만든 기술로 무기·기체를 생산하는 **츠카사 코퍼레이션(TSUKASA CORPORATION)** 이 경제·군사·기술을 독점하고 국가까지 장악했다(정부는 형식만 남음).
- 시민의 일상은 감시 아래 있다: 순찰 **무인 드론**, 대화를 기록하는 보안망, **기업 발행 신분증**.
- 저항 조직 **레지스탕스**는 보급로 습격·해킹·무기 탈취로 맞서지만 늘 열세였다.
- 레지스탕스는 츠카사가 폐기한 인체 개조 실험체 **추온**을 발견해 멈춘 심장을 되살린다. 추온은 **〈프로젝트 시리즈〉의 실패작**이다.

## 인물
- **추온**: 19세, 레지스탕스. 납치되어 인체실험을 당했고, 불안정성 때문에 **'실험체 07호'**라는 꼬리표와 함께 폐기됐다. 차분하고 냉담하지만, 레지스탕스를 잃은 뒤로는 복수심에 거침이 없다. 약자에게 연민을 보인다. 미식가이자 대식가로, 잃어버린 일상의 흔적이다.
- **E.G.O(에고)**: Enhanced Guidance Organism(강화 전술 유기체). **츠카사 무기산업의 최고 걸작인 지능형 카타나**로, 원래 레지스탕스 리더가 쓰던 검이다. 지나친 자율성 때문에 "예측 불가능한 무기"로 폐기 대상이 됐다. 여유롭고 농담을 즐기지만 냉철한 전략가다. 추온을 늘 **이름으로** 부른다(츠카사는 "07호"라고 부른다).
- **Type-D**: 추온과 같은 실험체 시리즈의 또 다른 산물이고, **남성("그")** 이다. 츠카사 본사 격납고에서 추온을 막아선다.
- **과학자 츠카사**: 보스전 승리 직후 직접 모습을 드러낸다.

## 인게임 시나리오 (현재 데모 범위)
1. **씬 A 튜토리얼 = 가상현실 훈련**("가상현실 부팅 완료", "내일 싸우러 가기 전 마지막 훈련"). 대사 스크립트에 단계별 대사가 있다.
2. **씬 B 츠카사 로비**(본사 빌딩): 레지스탕스가 정보 유출로 전멸한 뒤 추온이 복수와 진상 규명을 위해 침입한다. 경보 "침입자 감지. 방어 프로토콜을 가동합니다." **프론트 뒤편에서 드론이 나온다.** 일반 엘리베이터는 비활성 상태이고, **프론트 뒤편의 엘리베이터만 활성**이다. 그 엘리베이터는 **격납고 층으로만** 간다("놈들이 일부러 열어둔 길인가").
3. **씬 C 격납고 보스전**: 문이 서서히 열리고 걷기로 진입한다. Type-D와 싸운다.
4. **엔딩**: Type-D를 쓰러뜨린 직후 츠카사 등장 — **"결국 일어나 버렸나.. 하지만 넌 아직 내가 설계한 궤도 위를 걷고 있을 뿐이다."**

## 현재 게임과의 차이 (고칠 것)
- Level_Facility 캡슐 라벨 "TYPE-E CH-01 / ESCAPED" → 정식 설정은 **SUBJECT 07(실험체 07호)**, 상태 **DISPOSED(폐기)**.
- 상층을 "B1 연구동"으로 설정했지만 기획은 **츠카사 본사 로비**다(프론트 데스크, 비활성 엘리베이터 뱅크, 프론트 뒤 활성 엘리베이터). 실험체 캡슐은 로비의 **'프로젝트 시리즈' 기업 전시물**(무기·기체 쇼룸)로 재해석하면 설정과 맞는다.
- 로비·튜토리얼 대사를 대사 스크립트와 대조해서 맞춘다(EGO 말투: 여유·농담, 추온: 단호·짧게).
- 엔딩의 **츠카사 등장 대사**가 클리어 연출에 있는지 확인하고, 없으면 추가한다(홀로그램 등장 등).
- 튜토리얼 "TEST RANGE"는 **가상현실 훈련** 연출(VR 그리드, "SIMULATION")과 맞춘다.
