# 대사 스크립트 v2 (게임 내 전체 대사)

데이터 원본: `Assets/Resources/Dialogue/DialogueTable_KO.asset` (DialogueTable). 이 문서는 기획 검토용 사본이며, 수정은 에셋에서 키 단위로 한다.
키가 없으면 각 호출부의 기존 문구로 폴백한다. 자막 한 줄은 약 28자 이내(`/`= 줄바꿈).

- 캐릭터 톤: **EGO** 여유·농담·날카로운 전술 분석, 추온을 항상 "추온"으로 부름 / **추온** 짧고 단호, 숨은 다정함, 먹보(개그 3회 한정) / **System** 건조한 기업 안내 / **Type-D** 합성 음성 태그 / **츠카사** 엔딩 정사 대사(원문 고정).
- 대사 표시: 기본 켜짐 (`ExhibitionPrototypePresentationPolicy.DialogueEnabled`, PlayerPrefs `chuon.dialogue.enabled`, QA `-qaDialogue` 강제 켜짐). 전투 bark 는 `chuon.dialogue.barks`.
