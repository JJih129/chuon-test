# 전시 키오스크 모드 (PlayX4 2026)

공개 부스에서 방문객이 번갈아 플레이하는 환경을 위한 모드다. **기본은 꺼져 있고**, 켜지 않으면 게임 동작은 바뀌지 않는다.
코드: `Assets/Scripts/Exhibition/` (자체 부트스트랩, 씬·프리팹 수정 없음). 로직 테스트: `Assets/Scripts/Exhibition/Editor/KioskLogicTests.cs` (EditMode).

## 1. 켜는 방법

| 방법 | 범위 | 비고 |
|---|---|---|
| 명령줄 `-kiosk` | 이번 실행만 | 부스 PC 바로가기에 넣는 것을 권장 |
| 스태프 패널 `[1]` 토글 | 영구 저장 (PlayerPrefs `chuon.kiosk.enabled`) | 다음 실행에도 유지 |
| 명령줄 `-noKiosk` | 이번 실행만 강제로 끔 | 저장값보다 우선 |

- QA/PV 자동화 명령줄(`-qa…`, `-pv…`)이나 배치 모드에서는 `-kiosk` 를 함께 주지 않는 한 항상 꺼진다 (저장값 무시).
- 바로가기 예: `"D:\Chuon\ChuOn.exe" -kiosk`

### 스태프 패널 (숨김 콤보)
- 키보드 **Ctrl + Shift + K** 를 **3초** 누르고 있기, 또는 패드 **LB + RB + View(Select)** 3초.
  (F1·F12 는 개발 빌드에서 씬 이동·디버그 HUD 단축키라 쓰지 않는다.)
- 키오스크가 꺼져 있어도 열린다. 열려 있는 동안 게임은 일시정지된다.
- 표시: 키오스크 상태, 세션 상한, 현재 장면·진행 중 세션 시간, 누적 세션 수·평균·최장·직전 길이, 종료 사유별 횟수(완주·시간 상한·방치·메뉴·스태프), 어트랙트 재생 수, 마지막 리셋 사유·시각, 통계 파일 경로, 찾은 어트랙트 영상 경로.
- 조작

| 키보드 | 패드 | 동작 |
|---|---|---|
| 1 | X | 키오스크 켜기/끄기 (영구) |
| 2 | Y | 강제 리셋 → 타이틀 (사유 "스태프") |
| 3 | – | 세션 상한 켜기/끄기 (영구) |
| 4 | – | 누적 통계 초기화 (세션 CSV 는 보존) |
| 0 두 번 | – | 게임 종료 (키오스크 중 유일한 종료 방법) |
| ESC | B | 닫기 |

## 2. 동작과 타이밍

| 항목 | 기본값 | 명령줄 |
|---|---|---|
| 게임 중 방치 → 카운트다운 | 90 s | `-kioskIdle <초>` (최소 5) |
| "계속하시겠습니까?" 카운트다운 | 10 s | `-kioskCountdown <초>` (1–60) |
| 타이틀 방치 → 어트랙트 | 60 s | `-kioskAttractIdle <초>` |
| 세션 상한 | 600 s (10분) | `-kioskSessionCap <초>` (0 = 끔) |
| 상한 경고 토스트 | 상한 60 s 전 | – |
| 상한 유예(시네마틱·전투 중) | 최대 90 s | – |
| 데모 종료 카드 | 12 s (3 s 후 아무 입력으로 넘김) | – |
| 커서 자동 숨김 | 마우스 정지 3 s (패드 사용 중 0.5 s) | – |
| 어트랙트 영상 지정 | 자동 탐색 | `-kioskVideo <경로>` |
| 창 모드 허용 | 전체화면 강제 | `-kioskAllowWindowed` |

### 방치 (게임플레이 씬: Tutorial, Level_Facility 등)
1. 키보드·마우스·패드 입력이 90 s 동안 없으면 츠카사 톤 오버레이 **"계속하시겠습니까? 10"** 이 뜨고 게임이 멈춘다.
2. 아무 입력 → 계속 (오버레이 닫힘, 게임 재개).
3. 0이 되면 **타이틀로 리셋**: 시간 배율 초기화(`GameTimeScale.ReleaseAll`), 오디오 일시정지 해제, 커서 복원, 시네마틱 시청 기록·체크포인트 재시작 플래그 초기화, 키 리바인딩 중이면 취소. PlayerPrefs(옵션)는 지우지 않는다.
- 시네마틱 재생·로딩 팁 표시·키 리바인딩 중에는 방치 시간이 쌓이지 않는다.

### 어트랙트 (TitleScene)
- 60 s 방치 → PV 영상 반복 재생 (영상 소리만, 타이틀 음악은 잠시 멈춤). 영상이 없거나 재생 실패 시 **대체 연출**: 타이틀 카메라를 천천히 흔들고 CHUON/추온 로고와 기능 문구(패링·퍼펙트 회피·브레이크·궁극기·Type-D)를 순환.
- 아무 버튼(또는 큰 마우스 이동) → 타이틀로 돌아온다. 그 입력이 타이틀 버튼을 누르지 않도록 UI 입력은 버튼을 뗀 뒤 0.2 s 후 재개된다.
- 영상 탐색 순서: `-kioskVideo` → `StreamingAssets/Kiosk/*.mp4` → `StreamingAssets/*.mp4` → `<exe 폴더>/PV` → `<exe 폴더>/../PV` (= `Builds/PV`, 빌드가 `Builds/<이름>/` 에 있을 때) → (에디터) `Builds/PV`. 파일명에 `web` 이 든 것을 우선 (`Chuon_PV_v2_web.mp4`).
- **권장**: 부스 빌드의 `ChuOn_Data/StreamingAssets/Kiosk/` 에 `Chuon_PV_v2_web.mp4` 를 복사.

### 세션 (10분 흐름)
- 세션은 타이틀에서 게임을 시작해 `BootScene`/플레이 씬에 들어갈 때 시작하고, 타이틀로 돌아올 때 끝난다 (실제 시간, 일시정지 포함).
- 9:00 → 우상단 토스트 "체험 시간이 1분 남았습니다."
- 10:00 → (시네마틱·보스/잡몹 전투 중이면 끝날 때까지 최대 90 s 유예) **데모 종료 카드**: `PLAYX4 2026 DEMO — 플레이해주셔서 감사합니다`, 츠카사 헤더, **QR 슬롯** → 타이틀.
- 크레딧까지 완주하고 타이틀로 돌아오면 같은 카드("끝까지 플레이해주셔서 감사합니다")를 타이틀 위에 보여 준다.
- **QR 이미지**: `StreamingAssets/Kiosk/qr.png` 를 넣으면 카드에 표시된다 (없으면 자리 표시 "QR").
- 빠른 재시작: 일시정지 메뉴의 **재시작**(현재 씬 다시) / **타이틀**(새 세션). 스태프는 패널 `[2]`.

### 부스 안전장치 (키오스크 켜짐일 때만)
- **게임 종료 차단**: Alt+F4, 창 닫기, 모든 "게임 종료" 버튼(`Application.wantsToQuit` 에서 거부). 타이틀·일시정지·사망 화면의 "게임 종료" 버튼은 숨기고 패드 내비게이션은 건너뛰도록 다시 잇는다. 다른 선택지가 없는 화면(클리어 후 크레딧 오버레이)에서는 "타이틀로" 버튼으로 바뀐다. 종료는 스태프 패널 `0` 두 번.
- **디스플레이**: 해상도·전체화면·VSync·품질 컨트롤 잠금(비활성). 다른 경로(Alt+Enter, 타이틀 설정의 순환 버튼)로 바뀌면 1 s 안에 키오스크 시작 시점 값으로 되돌린다. 창 모드였다면 전체화면(창 없는 전체화면)으로 강제 (`-kioskAllowWindowed` 제외). 에디터에서는 동작하지 않는다.
- **볼륨**: 마스터 35% 미만, 음악/효과음/음성 15% 미만으로 내릴 수 없다 (슬라이더 최소값).
- **키 설정**: 방문객이 바꾼 키 바인딩은 세션이 끝날 때(타이틀 복귀) 키오스크가 켜진 시점의 설정으로 되돌아간다. 일시정지 옵션의 키 버튼은 잠근다 (타이틀 설정의 키 변경은 잠그지 않고 세션 종료 때 원복).
- **개발용 표시 끄기**: 전투 디버그 HUD(F12), 성능 진단 오버레이, 개발 씬 단축키(F1–F7), F10 테스트 모드(강제로 Off).
- 접근성 옵션(자막 크기, 번쩍임, 흑백 흡수 등)은 방문객이 바꿀 수 있고 유지된다. 필요하면 스태프가 옵션에서 되돌린다.

### 통계 파일
- `%USERPROFILE%\AppData\LocalLow\<회사명>\<제품명>\kiosk_stats.json` (= `Application.persistentDataPath`, 패널에 정확한 경로 표시): 누적 세션 수, 총/평균/최장/직전 길이, 사유별 횟수, 어트랙트 횟수, 마지막 리셋 사유·시각.
- 같은 폴더 `kiosk_sessions.csv`: 세션마다 한 줄 (`ended_at,seconds,reason,last_scene`). 사유: `completed`, `session_cap`, `idle`, `title_menu`, `staff`, `app_quit`.

## 3. 부스 설치 체크리스트 (스태프용)

> 아래 Windows 설정은 스태프가 직접 한다. 게임은 시스템 설정을 바꾸지 않는다.

**하드웨어·디스플레이**
- [ ] 모니터 해상도 1920×1080, 주사율 최대(60/120/144 Hz). Windows 배율 100% 권장.
- [ ] 게임을 키오스크 **끈** 상태로 한 번 실행 → 옵션에서 해상도·전체화면·품질 확정 → 종료. (키오스크는 켜질 때의 값을 기준으로 지킨다.)
- [ ] 바로가기에 `-kiosk` 추가. 시작프로그램(`shell:startup`)에 넣으면 재부팅 후 자동 실행.
- [ ] 어트랙트 영상 `StreamingAssets/Kiosk/Chuon_PV_v2_web.mp4`, QR `StreamingAssets/Kiosk/qr.png` 복사 → 스태프 패널에서 영상 경로 확인 → 타이틀에서 60 s 기다려 재생 확인.

**오디오**
- [ ] Windows 출력 장치 고정(헤드폰/스피커), Windows 볼륨 고정, "통신 활동 시 볼륨 줄이기" 끄기.
- [ ] 게임 옵션 마스터 볼륨 설정 (키오스크 중 하한 35%). 부스 소음에 맞춰 헤드폰 볼륨은 하드웨어로 조절.

**게임패드**
- [ ] 유선 연결 권장 (무선은 배터리·페어링 끊김). Xbox/DualSense 모두 지원, 화면 버튼 표기 자동 전환.
- [ ] 패드 하나만 연결 (여러 개면 모두 입력으로 받음). Steam 실행 시 Steam Input 이 패드를 가로채지 않는지 확인.
- [ ] 키보드·마우스도 함께 두면 방문객이 선택 가능. 스태프 콤보용 키보드는 손 닿는 곳에.

**Windows 설정**
- [ ] 전원: 화면 끄기·절전 **안 함**, 최대 성능 전원 계획, USB 선택적 절전 끄기.
- [ ] 화면 보호기 없음, 잠금 화면 자동 전환 끄기.
- [ ] 알림: **방해 금지(집중 지원) 켜기**, 전체화면 앱 실행 중 알림 끄기.
- [ ] Windows 업데이트 **일시 중지**(행사 기간), 사용 시간 설정.
- [ ] **고정 키 단축키 끄기** (Shift 5회 = 고정 키 팝업. Shift 가 회피 키라 방문객이 누르게 된다): 설정 > 접근성 > 키보드 > 고정 키 > "바로 가기 키" 끄기. 필터 키(오른쪽 Shift 8 s)도 같이 끄기.
- [ ] Xbox Game Bar(Win+G) 끄기, 패드 Xbox 버튼으로 Game Bar 열기 끄기.
- [ ] 백신·런처·클라우드 동기화 팝업 끄기 (Steam/Discord 오버레이 등).
- [ ] 방화벽 창이 처음 실행 때 뜨면 "취소" (네트워크 미사용).
- [ ] Windows 키·Alt+Tab 은 게임에서 막을 수 없다 → 키보드를 쓰면 Windows 키 잠금 기능이 있는 게이밍 키보드 권장, 또는 스태프가 주시.

**운영**
- [ ] 개장 전: 스태프 패널 `[4]` 로 통계 초기화 (CSV 는 계속 누적).
- [ ] 막히거나 이상하면: 스태프 콤보 → `[2]` 강제 리셋. 그래도 안 되면 `0` 두 번으로 종료 후 재실행.
- [ ] 폐장 후: `kiosk_stats.json`, `kiosk_sessions.csv`, `Player.log` 백업.

## 4. 알려진 제한 · 다른 파일에 필요한 후크
- 체크포인트 재시작 플래그(`LobbyManager.s_skipToLowerFloorOnNextLoad`, `InfiltrationTutorialDirector.s_resumeStep`)는 리셋 때 리플렉션으로 지운다. 해당 파일에 공개 `ClearCheckpointState()` 가 생기면 교체 권장.
- 일시정지 메뉴 "재시작"은 현재 씬 재시작이다. "새 방문객용 처음부터" 버튼이 필요하면 `PauseManager` 에 `KioskDirector.RequestResetToTitle(KioskResetReason.Staff)` 를 부르는 버튼을 추가해야 한다 (공개 API 준비됨).
- Alt+Enter 전체화면 전환 자체를 막으려면 Player Settings > Resolution > "Allow Fullscreen Switch" 끄기 (현재는 1 s 안에 복원).
- "게임 종료" 버튼은 이름(`quit`/`exit`) 또는 라벨("게임 종료", "QUIT" 등)로 찾아 숨긴다. 새 종료 버튼을 다른 이름으로 만들면 목록(`KioskSafety.QuitLabels`)에 추가.

## 5. 플레이 검증 항목 (개발 빌드 또는 에디터 Play, `-kiosk` / 패널 토글)
- [ ] 방치 90 s → 카운트다운 → 입력 시 계속 / 0이면 타이틀, 예외 0 (Tutorial, Level_Facility 각각, 일시정지 메뉴 열린 상태 포함).
- [ ] 시네마틱 중에는 카운트다운이 뜨지 않음.
- [ ] 타이틀 60 s → PV 재생(소리 포함) → 아무 버튼 → 타이틀, 해제 입력으로 "게임 시작"이 눌리지 않음. 영상 없는 경우 대체 연출.
- [ ] 세션 9:00 토스트, 10:00 엔드 카드 → 타이틀, 보스전 중 유예. (`-kioskSessionCap 120` 으로 빠르게 확인)
- [ ] 크레딧 완주 → 타이틀 감사 카드.
- [ ] 타이틀·일시정지·사망 화면의 "게임 종료" 숨김 + 패드 ↑↓ 순환, Alt+F4 무시, 스태프 `0 0` 종료.
- [ ] 해상도/전체화면 잠금·복원(빌드에서만), 볼륨 하한, 키 리바인딩 원복, 커서 자동 숨김.
- [ ] 스태프 패널 콤보(키보드·패드), 통계 파일 생성·누적.
