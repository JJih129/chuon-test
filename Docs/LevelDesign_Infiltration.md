# 레벨 디자인: 침투 경로 시뮬레이션 (숨겨진 튜토리얼, 반복 13)

캐논(`Docs/Story_Reference.md`, 대사 `tut.open.*`): 레지스탕스가 **내일의 침투 경로를 재현한 VR 시뮬레이션**. "가상현실 부팅 완료" → "내일 싸우러 가기 전 마지막 훈련". 공간은 진짜 도시처럼 보이되(극동풍 근미래 기업 도시, 해 질 녘), 시뮬레이션 티는 **가장자리에서만** 낸다(경계 그리드 일렁임, 적 생성·재생성 시 그리드 디졸브, 사망 대신 "재동기화").
씬: `Assets/Scenes/Tutorial.unity`(같은 경로에 재구성 — Title/Boot/스킵·QA 흐름 그대로). 이전 사격장은 `Assets/Scenes/Archive/Tutorial_Range.unity`.
지오메트리: `Tools/ArtGen/tutorial_city_blender.py`(Blender 5.2 헤드리스) + `Tools/ArtGen/tutorial_textures.py` → `Assets/Art/ChuonPolish/Tutorial/`. 조립: `Tools/Chuon/Tutorial/Build Infiltration Map`(`Assets/Scripts/Tutorial/Editor/InfiltrationMapBuilder.cs`, 재실행 가능). 흐름: `InfiltrationTutorialDirector`(기존 `TutorialFlowController`·조건 검사기·`EGOGuideController`·대사 테이블 `tut.inf.*` 재사용).

## 동선 (북쪽 = 본사)

```
 [본사 포디엄 + 타워(TSUKASA 엠블럼, 220 m) — 시작부터 보이는 위니]
                     ⑥ 로비 유리문(시뮬레이션 종료 → Level_Facility)
                     ⑤ 측면 출입구 마당 (방패 집행관 + 바닥 터렛 → 궁극기)
                     ④ 하역장 플랫폼·셔터 통로 (압축)
  ③ 하역장 야드 (벽 터렛 = 빨강 큐, 컨테이너 엄폐 → 회복 → 퍼펙트 회피) ← 서비스 골목(압축, 동쪽)
  ② 외곽 검문소 광장 (해방): 경비 안드로이드 2 — 락온·콤보 / 방어·패링(금색) → 차단기 개방
  ① 시작 골목길: 이동·시야(타워 응시)·회피, 스캐너 빔 커튼
```

## 비트 (가르치기 → 시험 → 비틀기)

| # | 장소 | 가르침 | 시험 / 비틀기 | 완료 조건(재사용 검사기) |
|---|---|---|---|---|
| 0 | 골목 시작 | VR 부팅 대사 | — | — |
| 1 | 골목 | 이동(WASD) | 가로등 아래 앰버 표식 | Movement(구역) |
| 2 | 골목 | 시야 | 거리 끝 **본사 엠블럼**을 화면 중앙에 | LookAt(엠블럼) |
| 3 | 골목 | 회피(Shift) 2회 | 스캐너 빔 커튼을 굴러서 통과(닿으면 경보·소량 피해) | 신규 `InfDodgeCountChecker` → 구역 |
| 4 | 검문소 | 락온(휠) | 등 돌린 순찰 안드로이드 | LockOn(안드로이드) |
| 5 | 검문소 | 약공·강공 | 약 3 + 강 1 적중(죽으면 시뮬레이션이 재생성) | 신규 `InfMobHitChecker` |
| 6 | 검문소 | 방어(E) | 부스에서 나온 2번째 안드로이드의 일반타 | Guard |
| 7 | 검문소 | 패링 — **금색 3타** | 패링 1회(실패해 쓰러뜨리면 재생성 = 재도전) | Parry |
| 8 | 검문소 | 게이팅 | 남은 경비 처치 → 차단기 개방 | 신규 `InfMobsDefeatedChecker` |
| 9 | 하역장 | **빨강 = 회피 전용** | 벽 터렛 연사 2회를 맞지 않기(컨테이너 엄폐·옆걸음) | 신규 `InfRedCueSurviveChecker` |
| 10 | 하역장 엄폐 | 회복(Q) | 체력 42%에서 앰플 | Heal |
| 11 | 하역장 플랫폼 | 퍼펙트 회피(비틀기: 같은 빨강을 피하지 않고 직전 회피) | 바닥 터렛, 실패 3회부터 판정 보조 | PerfectDodge |
| 12 | 측면 출입구 | 방패 = 정면 약공 막힘 → 강공/측면 | 가드 붕괴 1회(터렛 직선은 집행관 뒤로) | 신규 `InfGuardBreakChecker` |
| 13 | 측면 출입구 | 궁극기 1회(시뮬레이션이 게이지 충전) | 집행관 처치 | Ultimate |
| 14 | 로비 유리문 | 훈련 종료 | 문 패널(F) → "SIMULATION TERMINATED" → Level_Facility | Zone + 기존 `TutorialExitInteractableBridge` |

목표 길이: 첫 플레이 5–7분(이동 ~230 m, 달리기 4.5 m/s ≈ 50 s + 전투·대사).

## 적용 기법
- **위니**: 골목 축이 타워 정면과 일직선. 엠블럼은 붉은 발광, 꼭대기 항공 경고등. 어디서 보든 북쪽 하늘선에 있다.
- **리딩 라인·빛**: 가로등 열·차선·벽의 백색 라인 조명이 다음 목표로 수렴. 진행 방향 끝이 가장 밝다(검문소 투광등, 하역장 셔터 위 앰버 회전등, 로비 유리 너머 백색).
- **압축 → 해방**: 골목(압축) → 검문소 광장(해방) → 서비스 골목 4 m(압축) → 하역장 야드(해방) → 셔터 통로(압축) → 측면 마당 → 로비 앞 현관(압축, 문 너머 밝은 로비).
- **게이팅**: 검문소 차단기(경비 처치), 하역장 셔터(터렛 정지), 측면 출입구(집행관). 잠긴 문 = 붉은 표시등, 열린 문 = 앰버.
- **색 언어**: 빨강 = 츠카사·위험(터렛 레이저, 엠블럼, 금지 표지), 앰버 = 상호작용·통로(목표 표식, 문 패널, 열린 게이트), 흰색 = 정보(표지판·가로등). 시안은 VR 시스템 오버레이에만.
- **안전한 연습 공간 → 시험**: 각 교전 앞에 적 없는 구간(골목, 서비스 골목, 셔터 통로). 회복은 엄폐 칸에서.
- **환경 스토리텔링**: 순찰 감시 드론(탐조등), ID 게이트·스캐너, 슬로건("질서가 곧 안전입니다", "감시는 보호입니다", "NO ID · NO ENTRY"), 하역장 "TSUKASA LOGISTICS / PROJECT SERIES 반입", 검문소 수배 홀로그램.
- **소프트 실패**: 사망 없음. 체력 25% 이하 → "재동기화"(VR 오버레이) → 마지막 체크포인트로 복귀·체력/앰플 복구·해당 레슨 적 재생성. 레슨 실패(가르칠 적이 먼저 죽음)도 재생성으로 재도전.
- **카메라**: `SoulsGameplayCamera`(Level_Facility와 동일 리그). 전투 공간 중앙은 비우고, 소품은 벽에 붙이고, 얇은 소품은 오클루전 페이더 대상.
