# 레벨 디자인: 츠카사(TSUKASA) 격리시설 (Lobby + MainScene 통합)

목표: 지금 따로 있는 `Lobby`(드론 교전)와 `MainScene`(엘리베이터 도착 → 보스 TYPE-D)을 **한 씬, 한 건물**로 합쳐
로딩 없이 "침투 → 교전 → 하강 → 보스"가 이어지는 10분 내외의 완성도 높은 한 판을 만든다.
게임 속 기업: **츠카사(TSUKASA)**. 아트 방향(스타일 참고만): 사이버펑크 2077 아라사카(블랙·그래파이트, 절제된 레드 라인, 차가운 백색광) + 밀리테크(건메탈, 앰버 해저드, 스텐실).

## 1. 공간 구조 (수직 2층)

```
 [상층: 츠카사 본사 로비 = 기존 Lobby]            Y ≈ +40
   ① 진입 복도 ─▶ ② 아트리움 스카이덱(유리 바닥) ─▶ ③ 프론트 데스크 홀(드론 4, 데스크 뒤에서 출현) ─▶ ④ 데스크 뒤 전용 엘리베이터(격납고 직통)
                         │  (아래로 보스 격리실이 보임)                  │
                         ▼                                              ▼ 하강(페이드)
 [하층: B4 격리실 = 기존 MainScene 아레나]       Y = 0
   ⑤ 엘리베이터 도착(기존 연출) ─▶ ⑥ 보스 아레나(TYPE-D) ─▶ ⑦ 탈출 리프트 → 크레딧
```

- 상층 지오메트리를 Y+40으로 올려 두 레벨이 겹치지 않게 한다(조사 결과 둘 다 원점 근처에 있어 충돌).
- 상층 엘리베이터 하강이 끝나면 씬 로드 대신 **같은 씬 안에서** 페이드 → 하층 도착 연출을 재생한다.

## 2. 적용한 레벨 디자인 기법

| 기법 | 적용 |
|---|---|
| **랜드마크(위니, Disney "weenie")** | ② 관측 브리지에서 아래층 격리실의 붉은 격리장치와 갇힌 TYPE-D 실루엣이 보인다. 첫 장면부터 최종 목표를 보여 줘 동선이 저절로 생긴다. |
| **압축과 해방** | 좁고 낮은 진입 복도·엘리베이터(압축) → 높고 넓은 보스 아레나(해방). 하강 중 조명을 끊었다가 도착 시 아레나 전체를 드러낸다. |
| **가르치고-시험-비틀기 (기승전결)** | ③ 첫 드론 1기 단독 → 3기 동시(시험) → 보스에서 패링·브레이크 응용(비틀기). |
| **강도 곡선 / 페이싱** | 진입(낮음) → 관측 브리지(긴장, 예고) → 교전(중간) → 하강(휴식·연출) → 보스(최고) → 탈출(해소). 전투 사이에 숨 돌릴 구간을 반드시 둔다. |
| **리딩 라인·브레드크럼** | 바닥 앰버 해저드 라인과 천장 백색 라인 조명이 다음 목표(엘리베이터)로 수렴. 진행 방향 끝에 가장 밝은 광원. |
| **색 언어(어포던스)** | 레드 = 츠카사(기업)/위험/보스, 앰버 = 상호작용·통로(엘리베이터 패널, 문), 시안 = UI·홀로그램 정보만. 한 색 = 한 의미로 고정. |
| **게이팅** | 교전 홀 문은 드론 전멸 후 열림(기존 LobbyManager 조건 유지). 엘리베이터 패널은 앰버로 점등돼 상호작용 가능함을 표시. |
| **카메라 친화 아레나** | 보스 아레나 중앙 지름 ~24 m는 비워 둔다. 벽 가까이 소품은 0.4 m 이상 떨어뜨리지 않고 벽에 붙인다(락온 카메라 끼임 방지). 기둥은 외곽에만. |
| **체크포인트** | 보스 도착 연출 이후 사망 시 → 보스 앞 즉시 재시작(기존 `RequestSkipArrivalOnNextLoad` + 상층 스킵 플래그). 상층에서 사망 시 → 교전 홀 입구. |
| **환경 스토리텔링** | 본사 로비의 '프로젝트 시리즈' 쇼룸: TYPE-A~C 캡슐(TERMINATED), 추온의 빈 캡슐(SUBJECT 07 / 실험체 07호 — DISPOSED, 깨진 유리), 프론트 데스크 뒤 TSUKASA 로고 홀로그램, 측벽의 비활성 엘리베이터(LOCKDOWN). 대사 없이 세계관(기업의 인체실험)을 전달. |
| **시야 정리(네거티브 스페이스)** | 전투 공간에는 장식을 두지 않고, 장식은 외곽 벽·천장에 몰아 실루엣 가독성을 지킨다. |

## 3. 구현 계획 (원본 보존)

1. `Assets/Scenes/Level_Facility.unity` 새로 생성 — MainScene을 복제한 뒤 Lobby의 레벨 지오메트리·LobbyManager·드론 스폰·트리거를 Y+40으로 옮겨 합친다. **Lobby.unity / MainScene.unity 원본은 그대로 둔다.**
2. 중복 제거: PlayerRoot·Player_HUD·카메라·EventSystem·PauseCanvas·GameSceneBinder는 MainScene 것 하나만 유지하고 LobbyManager 참조를 재연결.
3. 코드(최소 수정):
   - `LobbyManager.CoTransitionFromElevator`: `LoadScene` 대신 이벤트 `ElevatorDescentFinished` 발행(씬 로드 없는 페이드).
   - `MainSceneArrivalController`: `playElevatorArrivalOnSceneStart=false` 지원 + `BeginArrivalFromLobby()` 공개 메서드. Clear/Exit/Assist/PostClear 컨트롤러는 전이 플래그를 실시간으로 읽게 변경.
   - `GameSceneBinder`: 씬 이름 비교 대신 직렬화 플래그.
   - 보스는 하강 전까지 `SetExternalIntroPaused(true)` + 비주얼 숨김.
   - 탈출 출구는 `explicitExitRoot` 지정(로비 elevator와 이름 충돌 방지).
4. 빌드 설정: 새 씬이 검증되면 `Lobby`·`MainScene` 대신 `Level_Facility`를 넣고 Tutorial 출구의 `sceneName`만 바꾼다. 개발 단축키 F2/F3 갱신.
5. 검증: QA 봇(`QaCombatBot`)으로 상층 교전 → 하강 → 보스까지 자동 진행, 씬 투어 스크린샷.
