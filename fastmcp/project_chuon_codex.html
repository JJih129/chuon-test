Recommended Workflow

  1. Start Unity and wait for editor compilation to settle.
  2. Run health_check to verify project root, editor log, and bridge port.
  3. Open one target scene such as MainScene, Lobby, or Tutorial.
  4. Use scene graph and targeted object commands before editing runtime scripts.
  5. Refresh assets after generated scripts or scaffolds are written from FastMCP.
  6. Use Play Mode tools only after the bridge reports a healthy editor state.

Generated Script Defaults

The current FastMCP server generates Unity scripts under Assets/Scripts/Generated and feature scaffolds under Assets/Scripts/Features. The default namespace for scaffolds is ProjectChuOn.

Editor Bridge Scope

The Unity editor bridge currently supports scene creation and opening, hierarchy reads, object creation and deletion, transform edits, component add and remove, prefab save and instantiate, asset search, inspector value writes, asset refresh, Play Mode entry and exit, and a basic 3D player rig generator.

Run Command Template

python fastmcp/fastmcp_server.py
This repository does not currently include its own local Python runtime. Run the server from an environment where the fastmcp package is already installed.

Project Notes

This is a Unity action project with scene flow centered around boot, title, lobby, tutorial, and main combat scenes. The script layout suggests active work across combat, player state, guard or parry logic, UI, enemy behaviors, and ultimate skill presentation.
